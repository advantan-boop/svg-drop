# SVG-drop — сборщик иллюстраций из готовых компонентов

Веб-сервис собирает векторные композиции только из объектов исходной библиотеки:
**10 предметов × 2 варианта** (главный цветной и фоновый монохромный) = 20 иллюстраций,
каждая в двух детализациях: **L** (подробная) и **S** (упрощённая для мелких размеров),
плюс 3 декоративных фона и 3 палитры из Figma-файла «Тестовое | иллюстрации».

Новые объекты сервис не генерирует. В композицию попадают те же `path`, что в исходнике:
меняются только положение, масштаб, поворот и цвета по палитре. Это проверено: пути книги
в экспортированном SVG совпадают с исходником побайтно.

**Демо:** https://advantan-boop.github.io/svg-drop/

**Видео-демонстрация (1 мин):** [docs/demo.mp4](docs/demo.mp4) — оба сценария, варианты раскладки, перекраска, ручное редактирование, своя палитра, смена формата, экспорт SVG.

## Запуск

```bash
cd app
npm install
npm run dev            # http://localhost:5173
```

## Что умеет

| Требование ТЗ | Как сделано |
|---|---|
| Сценарий 1: метафора или заголовок → композиция | Слова запроса сравниваются с тегами и синонимами объектов без учёта окончаний; недостающие предметы добавляются из подходящей тематической группы. Выбор всегда только из каталога. |
| Сценарий 2: названия компонентов → композиция | Режим «Компоненты»: `книга, лампа, ручка`; распознаются и падежи, и синонимы. |
| Автоматическая компоновка | 4 варианта сразу (раскладки «Собранно», «Со смещением», «Под заголовок», как в примерах из Figma) и кнопка «Ещё варианты». |
| Загрузка или готовая библиотека SVG | Встроенная библиотека плюс кнопка «+ SVG» для своих файлов (сохраняются в браузере). Свои SVG тоже перекрашиваются под палитру: каждый их цвет получает роль ближайшего цвета библиотеки, контуры и белый не меняются. Для отдельного объекта перекраску можно выключить. |
| Векторная структура, цвета, пропорции | Разметка объекта вставляется без изменений; все предметы сцены масштабируются **одним** коэффициентом. |
| Холст: добавить, переместить, повернуть, дублировать, удалить | Перетаскивание из библиотеки или клик, рамка с уголками (масштаб) и кружком (поворот, ⇧ — шаг 15°), ⌘D, ⌫, стрелки, ⌘Z / ⇧⌘Z. |
| Порядок слоёв, сцена из разных иллюстраций | Панель слоёв (↑↓, скрыть), `[` `]`, перевод объекта между главным и фоновым вариантом. |
| Выбор размера | Форматы 1200×630, 1080×1080, 1080×1920, 1920×1080, 1080×1350 и детализация L/S. |
| Цветовая схема, загрузка палитры, автоперекраска | 3 палитры из Figma; правка любого цвета пипеткой; загрузка палитры списком HEX, `.txt` или `.json` (`{background:[…], objects:[…]}`). |
| Экспорт в SVG | «Скачать SVG» и «Копировать» (вставка в Figma через ⌘V даёт редактируемые векторы). В файле нет растра, слои сгруппированы и подписаны `data-object`. |

## Архитектура

```
Размер L.svg / Размер S.svg      ← экспорт фреймов «Библиотека компонентов» из Figma
        │  app/scripts/extract.mjs        нарезка плоского SVG на объекты
        ▼
extract/{L,S}/*.svg + manifest   ← кластеризация фигур по пересечению габаритов
        │  app/scripts/build-library.mjs  имена, теги, роли, пары L/S, палитры
        ▼
app/public/library/index.json + {L,S}/<id>-<main|background>.svg
        │
        ▼  браузер
library.ts  загрузка, кэш, разбор SVG (содержимое корневого <svg> + viewBox)
match.ts    подбор: метафора → id объектов (теги + стемминг) / список названий
compose.ts  авто-раскладка: главный объект → изометрические направления → вписывание в кадр
color.ts    перекраска по ролям палитры (замена fill/stroke, геометрия не трогается)
render.ts   сцена → SVG (холст, превью вариантов и экспорт используют один код)
App.tsx / Canvas.tsx  редактор
```

**Хранение.** Каждый объект — отдельный SVG в собственной системе координат (`viewBox`
повторяет координаты исходного холста Figma). Объекты описаны в `index.json`: имя, теги,
«роль» (`surface` — на него можно положить предмет, `tall`, `item`), вес и файлы для каждой
детализации и варианта.

**Извлечение.** Figma экспортирует фрейм плоско: около 1500 `path` без групп и имён.
`extract.mjs` считает габариты каждой фигуры и объединяет пересекающиеся. Если кластер
слишком большой, значит два соседних предмета задели друг друга: такой кластер пересобирается
с более строгим порогом. Отдельно распознаются фоны (квадраты с `transform`), образцы палитр
(прямоугольники 500×158) и подписи (одиночный широкий контур текста; они отбрасываются).

**Переиспользование.** На холсте объект — это `<g transform="translate rotate scale translate">`
вокруг неизменённой разметки. Идентификаторы внутри (clipPath) получают префикс экземпляра,
поэтому один объект можно вставлять много раз.

**Перекраска.** Все объекты нарисованы в палитре «Лаванда». У каждого её цвета есть роль:
фон светлый/средний/тёмный, акцент 1–3. При выборе палитры цвет заменяется на цвет той же
роли; чёрный контур и белый общие. У загруженных SVG свои цвета, поэтому каждому из них
назначается роль ближайшего (по восприятию) цвета палитры-источника. Почти чёрные, почти белые
и серые цвета считаются контурами и бликами и не меняются. Обрабатываются атрибуты `fill`/`stroke`,
`style="fill:…"` и CSS в `<style>`. Так же перекрашены примеры в Figma: например, сиреневые
наушники на персиковом фоне становятся персиковыми.

**Компоновка.** Главный объект — самый «тяжёлый» (книга, папка, лампа). Остальные ставятся
вдоль изометрических диагоналей (30°/150°/210°/330°) в ближайшее свободное место. Пересечения
считаются по «сжатому» прямоугольнику, поэтому предметы касаются, как в примерах. Мелкий
предмет может лечь на «поверхность» (телефон или ручку на книгу, монету на кошелёк). Кластер
вписывается в область раскладки единым масштабом. Слои сортируются по глубине: что ниже в
кадре, то ближе к зрителю. Свободные места заполняются монохромными фоновыми объектами.

Пересобрать библиотеку из новых экспортов Figma:

```bash
cd app
node scripts/extract.mjs ../source/L.svg ../extract/L L
node scripts/extract.mjs ../source/S.svg ../extract/S S
node scripts/build-library.mjs
```

## Примеры

В `examples/` лежат три композиции, собранные тем же кодом (`npx tsx scripts/examples.ts`):

1. «Как накопить на мечту» — монета, кошелёк, смартфон; «Персик», «Собранно», 1200×630.
2. «Учёба по вечерам» — лампа, книга, ручка; «Лаванда», «Со смещением», 1200×630.
3. «Подарок к 8 марта» — ваза, книга, наушники; «Мята», «Под заголовок», 1080×1080.
